# v3.0.0 — first-party Hugo theme and company standards

> Brand moved to its first-party Hugo theme and adopted company standards.


## Highlights

- Migrated the documentation renderer from Docsy to the first-party
  projectious.work Hugo theme.
- Added locally reviewable company engineering standards and the Brand
  application profile.
- Published a generated machine-readable brand manifest and offline,
  read-only MCP contract.

See the repository
[change log](https://github.com/projectious-work/brand/blob/main/CHANGELOG.md)
for the complete notes and migration details.
