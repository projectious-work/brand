Marks#

SVG is the default for interfaces, documents, slides, and the web. Use PNG only where a raster format is required. Choose the supplied light, dark, warm, or monochrome variant for its intended surface; do not recolour the canonical geometry.

Browse logo files before downloading a mark. The logo, wordmark, and name remain reserved brand assets even though this repository is public.

Templates and examples#

The documentation contains live, theme-idiomatic specimens for page shells, marketing surfaces, agent consoles, forms, status states, diagrams, slides, email, documents, and terminal configurations. Treat them as implementation patterns, not as evidence that a particular project or service exists.

Supply-chain note#

Published themes and offline documentation may self-host the three OFL font families and vendor a versioned Tabler outline subset. Ship the corresponding licence text and record the pinned version in the SBOM.
