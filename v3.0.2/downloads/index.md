# Downloads

> Tokens, manifests, logo assets, templates, and machine-readable projectious.work brand material.


Use generated or canonical assets from this page. Do not copy values out of a
screenshot or recreate a mark from its appearance.

## Tokens and manifests

| Download | Use |
|---|---|
| [CSS custom properties](/downloads/tokens/variables.css) | Framework-neutral semantic and primitive tokens |
| [JSON tokens](/downloads/tokens/tokens.json) | Build tools, generators, audits, and non-CSS consumers |
| [Tailwind configuration](/downloads/tokens/tailwind.config.js) | Tailwind projects that need the same scales and roles |
| [Brand manifest](/downloads/brand-manifest.json) | Versioned allowlist for assets and AI/MCP discovery |

## Marks

SVG is the default for interfaces, documents, slides, and the web. Use PNG only
where a raster format is required. Choose the supplied light, dark, warm, or
monochrome variant for its intended surface; do not recolour the canonical
geometry.

[Browse logo files](/docs/logo/files/) before downloading a mark. The logo,
wordmark, and name remain reserved brand assets even though this repository is
public.

## Templates and examples

The documentation contains live, theme-idiomatic specimens for page shells,
marketing surfaces, agent consoles, forms, status states, diagrams, slides,
email, documents, and terminal configurations. Treat them as implementation
patterns, not as evidence that a particular project or service exists.

## Supply-chain note

Published themes and offline documentation may self-host the three OFL font
families and vendor a versioned Tabler outline subset. Ship the corresponding
licence text and record the pinned version in the SBOM.
