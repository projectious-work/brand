{{- /* The single primary action in a view. {{< pj-action href="#release-check" >}}Review release check{{< /pj-action >}} Exists so a content file never has to hand-write an anchor with classes on it. The same call renders the same control wherever this public shortcode and the specimen stylesheet are mounted, avoiding hand-written button drift. It emits the brand's own accent button rather than a theme's (`btn btn-primary`, or a Tailwind stack), so the accent-solid fill and the 4.72:1 contrast rule come from the system rather than from whichever framework is underneath. Takes either `href` for an external or absolute target, or `page` for an internal one, which resolves through relref so a broken internal target fails the build instead of shipping. Markdown's own link syntax cannot do this: attaching a class with `[label](url){.some-class}` needs Goldmark's *inline* attribute support, which Hugo does not enable — the braces render as literal text on the page. */ -}} {{- $href := "" -}} {{- with .Get "page" -}} {{- $href = relref $ . -}} {{- else -}} {{- $href = $.Get "href" | default ($.Get 0) -}} {{- end -}} {{- with $href -}} {{ $.Inner | $.Page.RenderString }} {{- else -}} {{- errorf "pj-action: needs a page or href argument, in %s" $.Page.Path -}} {{- end -}}
