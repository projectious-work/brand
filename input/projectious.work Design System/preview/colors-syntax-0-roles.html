Only the three neutrals live in the blue-grey band, separated by lightness; every chromatic role holds its own hue. Weight and italic carry structure alongside colour — keyword 700, type 600, invalid 600, function 500, comment and decorator italic — so the palette survives greyscale. Dark is the default. Note the two dark surfaces are not the same: a terminal keeps the black-ish #0e1720, while a code panel lifts to #131e2b so it reads as a panel rather than a hole in the page — every role still clears 4.79:1 there. Light roles sit at 4.5–5.8:1 (AA), pitched for chroma: held at AAA they collapsed toward black and the hues stopped being tellable apart, which defeats the point of a syntax palette.
