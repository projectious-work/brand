Floor 4.95:1 (dark) / 4.5:1 (light) against the terminal surface. The session uses the slots as they are actually consumed — 2/10 for success, 3/11 for warnings, 1/9 for errors, 8 for dimmed continuation, and the chrome roles for the status bar and the active pane border. Implementations for tmux, WezTerm, Kitty, iTerm2, Zellij and Ghostty are documented upstream.
