Solid and foreground do different jobs and are pitched separately: the solid is a graphic, so it can be vivid; the foreground is text on the tint and holds 4.5:1. Warning sits at hue 32–33° in every appearance — orange, but held clear of the brand accent at 11–12° so a caution is never mistaken for a call to action. The swatches carry a hairline because several tints sit close to the surface they print on. Each appearance re-picks its own solid, tint and foreground — the dark modes never reuse a light value at lower opacity. The ratio shown on each tint is measured live from the resolved tokens, so it cannot drift from the palette. Navy dark inherits deep dark's status set unchanged.
