# Marketing site UI kit — projectious.work

A pixel-faithful recreation of the projectious.work marketing surface (header, hero, three-pillars panel, code/terminal showcase, conviction list, CTA, footer). Built from the master brand HTML in the source repo (`brand/html/projectious-brand-system-final.html` and `projectious-digital-experience.html`).

Open `index.html` for a single click-thru landing page composed from the components in this folder.

## Components
- `Header.jsx` — top nav with brand mark + product CTA
- `Hero.jsx` — display headline, sub, primary + secondary CTA, dark variant
- `Pillars.jsx` — three-column Cloud / Agile / Agentic AI panel
- `CodeShowcase.jsx` — dark terminal panel with syntax-themed snippet
- `Convictions.jsx` — numbered list of the brand's four convictions
- `CTA.jsx` — full-width dark CTA strip with accent button
- `Footer.jsx` — brand mark left, page metadata right
