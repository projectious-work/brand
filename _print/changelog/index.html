v3.0.1 — recovered design-system site

Restores the complete revised documentation and visual specimens.

Added#

  • Recovered the revised foundation, interface, theme, governance, machine, and legacy-alignment documentation that did not enter v3.0.0.
  • Added an on-site change log with a complete historical release index.
  • Added semantic colour specimens and richer automatic inline colour chips.

Changed#

  • Retained milestone releases v1.0.0, v2.0.0, v2.1.1, and v3.0.0 in the release menu, followed by v3.0.1 and future releases.
  • Restored the complete header navigation and updated the announcement banner.

Fixed#

  • Moved the colour-scale, palette, semantic-swatch, and inline-chip rules into the specimen bundle compiled by the first-party Hugo theme.
  • Restored the intended space between the landing-page licence action and the footer.
  • Corrected repository check metadata to invoke the canonical Brand build and verification suite.

See the repository change log for the complete notes.

v3.0.0 — first-party Hugo theme and company standards

Brand moved to its first-party Hugo theme and adopted company standards.

Highlights#

  • Migrated the documentation renderer from Docsy to the first-party projectious.work Hugo theme.
  • Added locally reviewable company engineering standards and the Brand application profile.
  • Published a generated machine-readable brand manifest and offline, read-only MCP contract.

See the repository change log for the complete notes and migration details.

v2.1.1 — release and deployment corrections

Theme examples and release deployment now behave consistently.

Added#

  • Added the Hextra example’s colour-mode control to its header, alongside the search field and GitHub link.

Fixed#

  • Replaced literal Goldmark button attributes with the shared pj-action shortcode in the Hextra and Docsy examples.
  • Changed documentation deployment to publish archived versions and the latest site in one commit and push, avoiding a GitHub Pages race.

See the repository change log for the complete notes.

v2.1.0 — complete tokens and worked examples

Complete generated tokens, seven worked examples, and broader implementation guidance.

Highlights#

  • Expanded the generated CSS, JSON, and Tailwind token exports to cover the complete design system.
  • Added seven inspectable examples spanning product, mobile, presentation, document, diagram, and email surfaces.
  • Added responsive, composed-pattern, state, accessibility, portfolio, and collateral guidance.
  • Aligned the Docsy and Hextra examples with the documentation site’s shared brand sources.

See the repository change log for the complete notes.

v2.0.2 — clearer syntax roles

Syntax colours and examples became easier to distinguish across twelve languages.

Highlights#

  • Reassigned syntax hues using measured perceptual distance so keywords, operators, types, decorators, comments, and errors scan more clearly.
  • Added worked token-coverage examples for twelve programming and markup languages.
  • Corrected preprocessor directives, Rust attributes, and documentation-comment rendering.

See the repository change log for the complete notes.
