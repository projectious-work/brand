# Security Policy

This repository is primarily static brand assets and documentation (HTML, SVG, PNG, design tokens, LaTeX/Typst templates). Report the following privately rather than as a public issue:

- Malicious or unexpected content embedded in any asset (e.g., a template or HTML file that fetches remote resources, executes scripts, or exfiltrates data).
- Sensitive or unlicensed material you believe was committed by mistake (credentials, private data, third-party assets without a compatible license).
- Trademark or brand-impersonation abuse enabled by a gap in the published guidelines.

## Reporting

Email **info@projectious.work** with:

- Affected file(s) or path(s).
- What you found and why it's a concern.
- Suggested remediation, if known.

We aim to acknowledge reports within 5 business days. Do not open a public GitHub issue for security or unlicensed-material reports until a fix has landed.

## Scope

This policy covers the assets and templates in this repository. It does not cover third-party services referenced in documentation (e.g., Google Fonts, Unsplash, Pexels) — report issues with those directly to their maintainers.
