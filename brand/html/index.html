How to use
All files are standalone HTML — open any of them directly in a browser, no build step needed. Place all files in the same folder for the navigation links to work. The master document (1) contains the core design system with integrated logo lockups. The standalone sections (2–7) expand on each topic with full detail. The legal assessment (8) should be reviewed before public launch.
