■ Keywords (midnight-11) ■ Strings (orange-light) ■ Comments (code-comment) ■ Identifiers (midnight-12) ■ Operators (slate-11) Background: midnight-2
code-comment = #72889d — a dedicated syntax token, not a scale step. Steps 8–10 are border and solid-background roles (strong brd, solid bg, solid hvr); only steps 11–12 are text. Comments are 13px text, so they need 4.5:1: slate-8 gives 3.02:1 on midnight-2, and slate-11 is already taken by operators. This token measures 4.59:1 while staying dimmer than operators.

Dark mode strategy
Both modes equally supported · System preference + manual toggle
Light mode
White surfaces, midnight text, accent highlights
Dark mode
Midnight surfaces, light text, accent highlights
Implementation rules
Default follows prefers-color-scheme with manual override toggle persisted to localStorage. CSS custom properties swap per theme. Step 9 (solid accent) stays constant across modes. No pure #000 or #fff as text — use midnight-12 (#c5daf0 dark, #142438 light). Images get a subtle overlay (black-2 alpha) in dark mode. Code blocks are always dark regardless of mode.

Form rules
