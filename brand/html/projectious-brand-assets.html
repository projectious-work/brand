Illustration style
Abstract system diagrams — nodes, flows, pipelines in the brand palette
Visual language rules
Nodes: Rounded rectangles (radius-md). Midnight fill/stroke for infrastructure, orange fill/stroke for action/validation steps.
Connectors: Slate lines with open chevron arrow markers. 1.5px stroke.
Abstract layers: Dashed borders for policy/audit/abstract elements. Slate color, no fill.
Labels: Plus Jakarta Sans for node names, Source Sans 3 for descriptions. Text only — no icons inside nodes.
Complexity: 3–5 nodes maximum per diagram. If more are needed, split into multiple diagrams.
No: 3D renders, stock photos, gradients, drop shadows, decorative elements.
