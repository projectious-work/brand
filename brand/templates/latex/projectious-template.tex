\section{Introduction}

This template uses the projectious.work brand system. Body text is Source Sans 3
at 11pt; headings are Plus Jakarta Sans; code is IBM Plex Mono.

\subsection{Purpose}

Body copy sits in \code{ink} (\#142438, midnight-12) rather than pure black —
the brand does not use \#000 or \#fff as text. Supporting copy uses
\code{muted}. Emphasis can use \accentemph{the accent as text}, which resolves
to orange-11 so it stays legible at body size.

\subsubsection{Technical note}

The identity accent \#E05232 is reserved for fills, rules, and marks. Where the
accent must carry white text — a solid button or a filled bar — use
\code{accentsolid} (\#CC4528), which measures 4.72:1 against white.

\begin{brandnote}[Info]
Callouts use a 3pt left rule in the semantic colour on a subtle tinted
background, matching the on-screen pattern.
\end{brandnote}

\begin{brandwarn}[Warning]
Semantic colours carry meaning. Do not use them for visual variety.
\end{brandwarn}

\section{Tables}
