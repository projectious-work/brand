# Portfolio presentation

> Truthful status, social-preview, diagram, and demo patterns.


Portfolio presentation must make maturity and limitations easier to see, not
make prototypes appear more complete than they are.

- [Status treatments](/docs/portfolio/status/) define the approved maturity vocabulary.
- [Social previews](/docs/portfolio/social-previews/) define reusable repository artwork.
- [Diagrams and demos](/docs/portfolio/diagrams/) define evidence and source requirements.
- [Documents](/docs/portfolio/documents/) define the one-page CV, proposal, and memo pattern.

These patterns are projectious.work organisation assets. Bernhard Gerlach's
personal LinkedIn profile is a separate identity: use his name, portrait, and
first-person voice only with his approval. Do not turn a personal profile into
an organization-brand channel or imply personal endorsement.


- [Status treatments](https://projectious-work.github.io/brand/docs/portfolio/status/index.md) — Text-first maturity labels for truthful portfolio presentation.
- [Social previews](https://projectious-work.github.io/brand/docs/portfolio/social-previews/index.md) — Repository artwork that states category and maturity plainly.
- [Diagrams and demos](https://projectious-work.github.io/brand/docs/portfolio/diagrams/index.md) — Evidence-first architecture, flow, screenshot, and demo framing.
- [Documents](https://projectious-work.github.io/brand/docs/portfolio/documents/index.md) — The one-page document pattern — CV, proposal, memo — and how it paginates.
