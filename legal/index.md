## The short version

- Code, scripts, and design tokens are MIT-licensed.
- Plus Jakarta Sans, Source Sans 3, and IBM Plex Mono are SIL Open Font
  License 1.1.
- Tabler Icons are MIT-licensed.
- The projectious.work name, wordmark, logo, and derived product-line marks are
  reserved and are not granted under the code licence.
- A public source file is not automatically a public-domain asset.

When a new dependency, image, font file, icon subset, or generated artifact is
added, update both [provenance](/docs/governance/provenance/) and the
[SBOM](/docs/sbom/) in the same change.
