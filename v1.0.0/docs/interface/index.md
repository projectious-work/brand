# Interface

> The foundations applied to screens — components, code surfaces, dark mode, icons, and forms.

---

LLMS index: [llms.txt](/brand/v1.0.0/llms.txt)

---

Interface guidance applies the [foundations](/brand/v1.0.0/docs/foundations/)
to working software. Where a component appears here, its measurements are
normative — a 40px input is 40px, not "about 40px".

---

Section pages:

- [Components](/brand/v1.0.0/docs/interface/components/): The component set as live specimens — buttons, inputs, cards, tables, navigation, feedback, overlays, and data display.
- [Dark mode](/brand/v1.0.0/docs/interface/dark-mode/): Both modes are equally supported. The implementation rules that keep them in step.
- [Code](/brand/v1.0.0/docs/interface/code/): The always-dark code surface and the syntax theme, with measured contrast for every token.
- [Icons](/brand/v1.0.0/docs/interface/icons/): Lucide as the icon library, and how icons are sized and coloured.
- [Forms](/brand/v1.0.0/docs/interface/forms/): Input sizing, labels, focus, error, and disabled states.
