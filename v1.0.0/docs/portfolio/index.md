# Portfolio presentation

> Truthful status, social-preview, diagram, and demo patterns.

---

LLMS index: [llms.txt](/brand/v1.0.0/llms.txt)

---

Portfolio presentation must make maturity and limitations easier to see, not
make prototypes appear more complete than they are.

- [Status treatments](/brand/v1.0.0/docs/portfolio/status/) define the approved maturity vocabulary.
- [Social previews](/brand/v1.0.0/docs/portfolio/social-previews/) define reusable repository artwork.
- [Diagrams and demos](/brand/v1.0.0/docs/portfolio/diagrams/) define evidence and source requirements.

These patterns are Projectious organization assets. Bernhard Gerlach's
personal LinkedIn profile is a separate identity: use his name, portrait, and
first-person voice only with his approval. Do not turn a personal profile into
an organization-brand channel or imply personal endorsement.

- [Social previews](/brand/v1.0.0/docs/portfolio/social-previews/): Repository artwork that states category and maturity plainly.
- [Diagrams and demos](/brand/v1.0.0/docs/portfolio/diagrams/): Evidence-first architecture, flow, screenshot, and demo framing.
