# v2.0.2 — clearer syntax roles

> Syntax colours and examples became easier to distinguish across twelve languages.


## Highlights

- Reassigned syntax hues using measured perceptual distance so keywords,
  operators, types, decorators, comments, and errors scan more clearly.
- Added worked token-coverage examples for twelve programming and markup
  languages.
- Corrected preprocessor directives, Rust attributes, and documentation-comment
  rendering.

See the repository [change log](https://github.com/projectious-work/brand/blob/main/CHANGELOG.md)
for the complete notes.
