Getting startedDocumentation

One system, from tokens to documentation#

This site is built with the system it documents. The scales on the colour page are the scales styling this paragraph; the type ramp is the ramp setting this sentence. If a token changes, the documentation changes with it — there is no separate “brand site” theme to drift out of sync.

Three appearances, one contract

Light, navy dark, and deep dark share semantic roles while preserving useful surface depth.

Built for humans and agents

Readable guidance, generated downloads, clean Markdown, llms.txt, and a versioned MCP resource server.

Artifacts you can inspect

Live specimens translate the supplied preview cards, UI kits, slides, marks, and terminal examples into the documentation theme.

See the feature overview · Read the developer guide · Browse downloads

Built to be used with care#

The code and tokens are MIT. The brand marks are not. The documentation tells you which is which on every page, and the provenance inventory records the licence of every third-party dependency.
